    Install

    Installing it yourself

    Click Indicators isn't on the Geode index, so you install it from the file above instead of the in-game browser. It's still a totally normal Geode mod — dropping the file in the mods folder is all the index would have done for you anyway.

    1. Install Geode first if you haven't already, from geode-sdk.org/install. Then launch Geometry Dash once so Geode makes its folders.
    2. Close Geometry Dash. Geode only loads mods when the game starts up, so adding one to a running game does nothing. Easily the most common reason an install looks broken.
    3. Open your Geometry Dash folder. In Steam: right-click Geometry Dash → Manage → Browse local files. Usually:
      C:\Program Files (x86)\Steam\steamapps\common\Geometry Dash
      Not the one in AppData. There's a second geode\mods at %LOCALAPPDATA%\GeometryDash\geode\mods and it's the wrong one. That one holds settings, and a mod dropped in there is ignored with no error at all. Quick way to tell: the right folder is full of .geode files. The AppData one is full of folders named like hjfod.betteredit. Looking at folders means you're in the wrong place.
    4. Drop the file into geode\mods inside that folder. Leave the name as jackz.click-indicators.geode.
    5. Start the game. Click Indicators shows up in the Geode mods list and puts a button on the main menu.
    6. Sign in inside the mod with this same email and password.

    The download is one file covering Intel Macs and Apple Silicon, so you do not need to pick a version. If Geometry Dash is not installed through Steam, the path is the same from Geometry Dash.app onwards, wherever that app happens to live.

    1. Install Geode first if you haven't already, from geode-sdk.org/install. Then open Geometry Dash once so Geode sets itself up.
    2. Download the file above on your phone. Tapping Download in your phone's browser is enough, it lands in your Downloads folder. You don't need a computer for any of this.
    3. Open Geometry Dash and go to the Geode menu, then the mods screen.
    4. Tap "Install from file" and pick jackz.click-indicators.geode from your Downloads in the file picker that opens.
    5. Restart the game when it asks. Click Indicators then appears in your mods list and adds its button to the main menu.
    6. Sign in inside the mod with this same email and password.
    Free camera and the click editor won't work on a phone. They need a keyboard, so they're desktop only. Everything else, all five cue styles, sounds, calibration and macro downloads, works the same.

    Updating: grab the new file and swap it for the old one in the same geode mods folder as above, game closed. Your settings and saved macros stay put, they live outside the mod file.

    Uninstalling: delete it from that folder, or just switch the mod off in the Geode menu.
